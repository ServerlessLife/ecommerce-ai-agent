sample chat

A minimal product-Q&A chatbot: one search_products tool answers over a 194-product catalog seeded in DynamoDB — a real vector index queried via SearchVectors, embeddings from Amazon Titan. The agent is deployed as several backends below; use the chat window in the bottom-right corner.

Agent implementation

Try asking…

  • “What do I need for a game of basketball?” — the index ranks the Basketball and the Basketball Rim top.
  • “I need shoes for playing baseball.” — the Nike Baseball Cleats, by a wide margin.
  • “I want a scooter for city commuting.” — the Scooter Motorcycle first.
  • “I need food for my dog.” — the Dog Food, with the cat food as runner-up.
  • “I want wireless earbuds for running.” — the Beats Flex and the AirPods.
